# Leftover from MVP

The original MVP scope is largely in place. The remaining work from that plan is now captured here.

## Remaining areas

- Query-layer refinement: richer LINQ translation and expression support
- Additional provider support: Apache AGE and other graph backends
- Developer experience: interceptors, logging, and diagnostics
- Async-first execution polish and broader API consistency

Completed items from the original plan, such as the core graph context, node and edge lifecycle tracking, ontology builder, validation, and Neo4j persistence, are no longer listed here.
